## 11. 驗收流程

### 11.1 各 Phase 驗收步驟

```
1. 工程師完成開發
2. 依據上述驗收項目逐一測試
3. 在「通過」欄標記 ✅ 或 ❌
4. 若有 ❌，記錄問題描述並修復
5. 所有項目通過後，該 Phase 驗收完成
```

### 11.2 Phase 對應驗收範圍

| Phase | 週期 | 驗收範圍 |
|:---|:---|:---|
| Phase 1 | 第 1-2 週 | AC-0 (基礎設施) + AC-5 (向量化) |
| Phase 2 | 第 3-4 週 | AC-1 (RAG) + AC-2 (檢索) + AC-6 (回饋) |
| Phase 3 | 第 5-6 週 | AC-4 (Prompt) + AC-3 (評估) |
| Phase 4 | 第 7-8 週 | AC-NF (非功能需求) + 全面回歸測試 |
