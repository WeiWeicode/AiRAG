## 9a. 語義資料庫查詢法 (Semantic DB Query) (Phase 3)

| ID | 驗收項目 | 預期結果 | 通過 |
|:---|:---|:---|:---:|
| AC-DB.1 | 查詢設定檔 CRUD | 可建立/編輯/刪除查詢設定檔，欄位含表格用途、欄位說明；建立時自動產生向量並寫入對應知識庫 collection | ☐ |
| AC-DB.2 | 必定查詢 (is_default) | 標記為必定查詢的設定檔，即便問題與其語意無明顯關聯，仍會出現在候選清單最前面 | ☐ |
| AC-DB.3 | Schema 探索 | 可依連線設定檔列出資料表清單與指定資料表的欄位清單，供設定檔欄位設定使用 | ☐ |
| AC-DB.4 | 候選比對與人工選定 | 指定知識庫時，輸入問題能取得候選設定檔清單與 AI 選擇理由；選定後才產生 SQL 並執行查詢與摘要 | ☐ |
| AC-DB.5 | 唯讀安全與不限定知識庫 | 產生的 SQL 一律通過唯讀驗證（僅 SELECT/WITH）；未指定知識庫時能依序合併前 N 個候選結果直接生成回答 | ☐ |
